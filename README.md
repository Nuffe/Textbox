This project is a text editor built close as to scratch as i felt comfortable with, i wanted to try and understand the lower level parts more. <br>
For the rendering and input handling i use Pygame, I wanted to avoid the highter abstarctions of Tkinter as much as i could for learning purpuses. Tkinter is only used for the file dialog in this project.  <br>
In the edtor i implement a gap buffer in combination with a double linked list to take care of the text insertion, deletion and cursor movment. <br> 
It has been a good experiance in learning more about input handling, learning new data strucures and making them work together. <br>
